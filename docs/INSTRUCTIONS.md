## 1. Запуск на своём компьютере

Нужны Node.js 24, pnpm и PostgreSQL 17.

```bash
cd leados
pnpm install                 # заодно генерирует Prisma Client
cp .env.example .env         # впиши DATABASE_URL, остальное — по разделам ниже
pnpm db:deploy               # создать таблицы
pnpm dev                     # http://localhost:3000
```

- Демо-данные для знакомства: `pnpm db:seed` — только на пустой базе (с лидами откажется; `-- --force` удалит все лиды).
- Фоновый AI-воркер (оценка, дайджест, follow-up, утренняя сводка): `pnpm worker:ai` в отдельном терминале.
- Telegram-воркер чтения каналов — раздел 4.

## 2. Первая настройка

1. **«AI» → Правила.** Чем занимаешься, что не берёшь, как пишешь отклики, цены. В полях — черновик из описания LeadOS:
   поправь и **сохрани** (до сохранения AI правил не видит).
2. **«AI» → Кейсы.** Реальные проекты: для кого, что сделано, что это дало клиенту. AI ссылается только на них.
3. **«Холодный поиск» → Настройки.** Город и ниши.
4. **«Закладки».** Перетащи три кнопки на панель закладок.
5. **«Настройки».** Подключи Telegram-бота для уведомлений (раздел 9) и проверь, что в «Готовности окружения» нет красного.
6. **«Импорт».** Загрузи прошлых клиентов и сделки (раздел 10) — аналитика и рекомендации сразу заработают на истории.

## 3. Закладки: Kwork, карты, любая страница

«Закладки» → перетащи кнопку на панель закладок (⌘⇧B — показать панель). Не перетаскивается — «Скопировать код»,
создай закладку вручную и вставь код в поле адреса. Первый раз браузер может заблокировать окно — разреши
всплывающие окна для сайта.

| Закладка | Где нажимать | Что забирает |
|---|---|---|
| **→ LeadOS** | заказ на Kwork `kwork.ru/projects/…` или страница отклика `new_offer?project=…` | заголовок, описание, бюджет, срок, покупатель, число предложений |
| **→ LeadOS (карты)** | открытая карточка компании на Яндекс Картах или в 2ГИС | название, рубрики, телефон, сайт, адрес, рейтинг; сразу проверяет сайт |
| **→ LeadOS (любая страница)** | Авито, VK, FL.ru, Хабр Фриланс, сайт компании — что угодно | ссылку, заголовок, выделенный текст; телефон, email, Telegram из текста |

Для «любой страницы» **выдели текст объявления или поста** перед нажатием — так заголовок и контакты будут точнее.
Без выделения на сайте компании контакты ищутся по всей странице; на площадках — только в описании страницы.

В окне проверь поля и нажми «Добавить лид». Если лид уже есть (та же ссылка или тот же телефон) — окно покажет его.

**После смены адреса LeadOS** (localhost → Vercel → VPS) все закладки нужно удалить и перетащить заново.

## 4. Telegram-каналы

Воркер читает каналы и супергруппы от твоего аккаунта — только те, где ты состоишь — и только читает.
**На Vercel он не работает** (нужен постоянно запущенный процесс): запусти его на своём компьютере или любом сервере,
указав адрес LeadOS на Vercel.

**Один раз:**

1. https://my.telegram.org → API development tools → создай приложение, возьми `api_id` и `api_hash`.
2. В окружении LeadOS должен быть `API_TOKEN` (`openssl rand -hex 32`).
3. Войди в Telegram и получи строку сессии — в своём терминале, телефон, код и облачный пароль вводишь сам:

   ```bash
   cd leados/worker/telegram
   python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
   TG_API_ID=123456 TG_API_HASH=abc… .venv/bin/python login.py
   ```

   Напечатанная строка — `TG_SESSION`. **Она даёт полный доступ к аккаунту**: храни как пароль, не коммить, не пересылай.
   Отозвать: Telegram → Настройки → Устройства → завершить сеанс.

**Запуск:**

```bash
cd leados/worker/telegram
TG_API_ID=… TG_API_HASH=… TG_SESSION=… \
LEADOS_URL=https://твой-адрес LEADOS_API_TOKEN=<API_TOKEN> \
.venv/bin/python -m leados_tg
```

**В LeadOS → Telegram:** индикатор воркера станет зелёным, в «Мои каналы» появится список — жми «Следить».
Задай ключевые и стоп-слова; для каналов-лент заказов — режим «все посты». У нового канала читаются последние
50 постов, дальше — только новые, раз в 5 минут.

## 5. Холодный поиск: Яндекс Карты и 2ГИС

1. «Холодный поиск» → Настройки: город и ниши. Ниши, где уже были ответы и сделки, поднимаются наверх и показывают
   «отвечают N%» — ищи в первую очередь там.
2. У ниши нажми «Яндекс ↗» или «2ГИС ↗», открой карточку подходящей компании и нажми закладку **→ LeadOS (карты)**.
   В 2ГИС, если окно пишет «обнови страницу», нажми F5 на карточке и повтори.
3. LeadOS проверит сайт и покажет оценку: Горячий / Тёплый / Холодный с аргументами для звонка.
   Одна компания с Яндекса и 2ГИС распознаётся по телефону.

**Обзвон** — справа: сначала кому пора перезвонить, дальше самые перспективные. После звонка — результат:
«Не дозвонился» (напомнит завтра), «Перезвонить» (через 2 дня), «Интересно», «Не интересно».
Скрипт звонка под нишу — в карточке компании, «+ Скрипт звонка».

Проверка сайта смотрит только главную: «не видно онлайн-записи» значит «не нашёл на главной». Перед звонком открой сайт сам.

## 6. AI: оценка, черновики, дайджест

**Подключение:** ключ на https://console.anthropic.com → API Keys → `ANTHROPIC_API_KEY` → перезапуск.
На сервере запусти `pnpm worker:ai`; на Vercel задачи выполняются сами (раздел 13). Проверка — страница «AI».
Уже существующие лиды: «AI» → «Оценить неоценённые лиды».

**Само:**
- **Новый лид** получает оценку 0–100, вердикт «Брать / Подумать / Пропустить», тревожные признаки с объяснением и вопросы
  заказчику. Статус AI не меняет. Импортированные из таблиц лиды не оцениваются.
- **Утром** — дайджест новых лидов за сутки (раздел «Дайджест», карточка на дашборде, сводка в Telegram).
- **Зависшие лиды** («Контакт»/«Переговоры» дольше `STALE_DAYS` дней) получают черновик follow-up.

**По кнопке в карточке:** «Оценить», черновики (отклик на Kwork, сообщение автору поста, скрипт звонка, холодное сообщение,
follow-up, просьба об отзыве и рекомендации, предложение доработок), «Подобрать опции с AI» в сделке.
Правь текст → «Копировать» → отправь сам → **«Отправил»**: сообщение уйдёт в историю, новый лид перейдёт в «Контакт».
Отправленные тексты AI использует как примеры твоего стиля, в первую очередь те, что привели к сделке.

**Расходы:** Claude Opus 5 ($5 / $25 за 1M входных/выходных токенов; правила и кейсы кэшируются). Счётчик за 30 дней —
на странице «AI». Много лидов из Telegram, а оценивать все не нужно — `AI_AUTO_SCORE=false`, тогда только по кнопке.
Если модель откажется отвечать, запрос сам повторится на резервной модели Anthropic.

## 7. Сделки и оплата

В карточке лида блок **«Сделка и оплата»**.

1. **Сумма за работу** и режим оплаты («Целиком» или «Частями») → «Создать сделку». При статусе «Выигран» сделка
   создаётся сама — останется вписать сумму.
2. **Оплата целиком:** когда деньги пришли — «Оплачено целиком», при желании укажи способ (карта, СБП, Kwork…).
3. **Частями:** «Разбить неоплаченный остаток на части» → шаблон (50/50, 30/70, 30/40/30, 3 или 4 равные части),
   дата первой оплаты и шаг в днях → «Составить график». Части округляются до сотни, сумма частей всегда равна остатку.
   По мере оплаты жми «Оплачено» у каждой части. Просроченные части красные, попадают на дашборд и в утреннюю сводку.
   Свой график — «+ Платёж» с суммой и сроком.
4. **Чаевые:** «+ Платёж» → тип «Чаевые». Считаются отдельно и не уменьшают остаток по договору.
5. **Доп. опции:** «+ Опция вручную» или «Подобрать опции с AI» (онлайн-запись, интеграции, поддержка… с ценами по твоим
   правилам). Статусы: предложена → принята / отказ. **Принятые увеличивают сумму договора.** Если график уже составлен,
   появится подсказка «Не распределено по графику» — составь график заново или добавь платёж «Оплата опции».

Наверху блока — договор, получено, остаток, чаевые и полоса оплаты. Выручка в аналитике и «Получено за месяц»
на дашборде считаются **по отмеченным оплатам** — не забывай их отмечать.

## 8. Повторные продажи и рекомендации

- Через **14 дней** после закрытия сделки на дашборде появится «Попросить отзыв и рекомендацию», через **90** —
  «Предложить доработки». Черновики этих сообщений — в карточке («Черновики сообщений»). После «Отправил» напоминание
  снимется само; можно и вручную галочками в блоке сделки.
- Пришёл клиент по рекомендации — у нового лида источник «Рекомендация» и поле **«Кто порекомендовал»**.
  В аналитике появится «Кто приводит клиентов» — с кем стоит поддерживать отношения.

## 9. Уведомления в Telegram

1. В Telegram открой **@BotFather** → `/newbot` → получи токен.
2. Положи токен в `TELEGRAM_BOT_TOKEN` и перезапусти приложение (на Vercel — Redeploy).
3. Открой своего бота, нажми «Старт».
4. LeadOS → **«Настройки»** → «Найти мой чат». Бот пришлёт «LeadOS подключён».
5. Там же: утренняя сводка вкл/выкл, порог «горячего» лида, «Прислать сводку сейчас» — проверить, как выглядит.

Что приходит:
- **Утренняя сводка** (в `DIGEST_HOUR`, по умолчанию 8:00): лучшие новые лиды, оплаты (просроченные, сегодня, завтра),
  follow-up, кому перезвонить, повторные продажи. Если делать нечего — не приходит.
- **Горячий лид** — сразу после оценки: новый лид с баллом не ниже порога (75). Для Kwork это шанс откликнуться первым.

Одно и то же сообщение не приходит дважды, даже если cron или воркер запустились повторно.

## 10. Импорт прошлых сделок из таблиц

1. В Excel или Google Таблицах: одна строка — один клиент или сделка, первая строка — заголовки.
2. **«Импорт»** → загрузи CSV (Excel: Файл → Сохранить как → CSV) или скопируй таблицу целиком и вставь.
3. Проверь, какая колонка чем является (угадывается по заголовкам: «Клиент», «Телефон», «Сумма», «Оплачено», «Статус»,
   «Источник», «Дата», «Дата сдачи», «Ниша», «Комментарий», «Чаевые»…). Обязательна колонка с клиентом.
4. Выбери источник и статус по умолчанию и нужно ли считать выигранные сделки оплаченными (если колонки «Оплачено» нет).
5. Посмотри предпросмотр: предупреждения про нераспознанные суммы, даты и статусы → «Импортировать».

Понимает: суммы «50 000 ₽», «45к», «1.234.567»; даты «17.09.2026», «17.09.26», «2026-09-17» и числовые даты Excel;
статусы словами («оплачено», «в работе», «отказ», «переговоры»); оплату «да», «+», «нет» или суммой.
Дубли — тот же телефон, email или то же название в тот же день — пропускаются, список пропущенных строк покажется.
Если что-то пошло не так — внизу страницы **«отменить импорт»** удалит всё из этой загрузки.

## 11. Каждый день

1. **Утренняя сводка в Telegram** или **дашборд**: деньги и повторные продажи, дайджест, follow-up.
   Оплату, которая пришла, отмечай прямо на дашборде — «оплачено» рядом с платежом.
2. **Дайджест** → лучшие лиды → «Квалифицировать» / «Пропустить» прямо в списке → черновик → «Отправил».
3. **Много лидов сразу** (например, из Telegram): «Лиды» → отметь галочками → «Пропущен» / «Квалифицирован» / «Проигран».
4. **Холодный поиск** → обзвон. В карточке лида кнопки «Позвонить», «WhatsApp», «Telegram», «Почта» — в один тап с телефона.
5. **Воронка** — перетаскивай карточки между этапами (на телефоне — выпадающий список статуса). Выигранные — сумма, график, оплаты.

На телефоне разделы открываются кнопкой ☰ справа вверху, «+ Лид» всегда рядом.

**Резервная копия:** «Настройки» → «Данные» → скачать лиды и сделки и платежи в CSV (открываются в Excel). Файл лидов
можно загрузить обратно через «Импорт» — колонки распознаются сами, связь «кто порекомендовал» восстанавливается.

## 12. Аналитика и донастройка AI

**Аналитика** (период сверху):

| Блок | На что смотреть |
|---|---|
| Воронка по источникам | Где лиды теряются; договоры и получено по источнику, средний чек, срок до сделки |
| Получено за 12 месяцев | Деньги по месяцам оплаты, чаевые отдельно |
| Деньги по выигранным сделкам | Сколько ждём и сколько просрочено; как часто платят частями и оставляют чаевые; сколько приносят доп. опции |
| Кто приводит клиентов | Клиенты-рекомендатели и сколько принесли приведённые ими |
| Холодный поиск по нишам, звонки, оценка сайта | Какие ниши отвечают и платят; работают ли аргументы про сайт |
| Telegram-каналы | Каналы, из которых почти всё пропускаешь, — перевести на ключевые слова или убрать |
| Отправленные сообщения | Какой тип сообщений получает ответы |
| Качество AI | Растёт ли доля ответов с баллом; совпадает ли вердикт с твоими решениями; сколько правишь черновики |

**Донастройка AI:**
1. Не согласен с оценкой — в карточке «Оценка неверна?» → правильный вердикт и почему. Последние 15 поправок учитываются.
2. Раз в пару недель: «AI» → «Донастройка» → «Предложить донастройку» → «Применить» у предложений, с которыми согласен.

## 13. Деплой на Vercel

**Что нужно:** репозиторий на GitHub (или `vercel` CLI), база PostgreSQL в облаке, аккаунт Vercel.

1. **База.** Vercel → Storage → Marketplace → **Neon** (или Supabase). Нужны два адреса одной базы:
   - `DATABASE_URL` — **пулинговый** (у Neon хост с `-pooler`) — для приложения;
   - `DIRECT_URL` — прямой — для миграций.
2. **Проект.** Vercel → Add New → Project → репозиторий. Root Directory менять не нужно — приложение в корне.
   Build Command тоже настраивать не нужно: Vercel сам запускает `vercel-build` из `package.json`, который применяет
   миграции, генерирует Prisma Client и собирает приложение.
3. **Переменные** (Settings → Environment Variables, Production). Если база подключена через интеграцию
   (Prisma Postgres, Neon, Supabase), её переменные (`POSTGRES_URL`, `PRISMA_DATABASE_URL`, в том числе с префиксом
   проекта вроде `leados_POSTGRES_URL`) приложение понимает само — отдельный `DATABASE_URL` можно не создавать.
   Остальное: `BASIC_AUTH_USER`,
   `BASIC_AUTH_PASSWORD` (длинный — это единственная защита входа), `APP_URL` (адрес проекта, `https://….vercel.app`
   или свой домен), `CRON_SECRET` и `API_TOKEN` (`openssl rand -hex 32`), `ANTHROPIC_API_KEY`, `TELEGRAM_BOT_TOKEN`.
4. **Deploy.** После сборки открой адрес, войди, зайди в **«Настройки»** — все обязательные пункты зелёные.
5. **Deployment Protection** (Settings → Deployment Protection): для Production выключи Vercel Authentication —
   иначе Telegram-воркер и cron получат 401. Вход в LeadOS всё равно закрыт паролем `BASIC_AUTH_*`.
6. Переустанови закладки со страницы «Закладки», подключи бота в «Настройках», запусти Telegram-воркер (раздел 4)
   с `LEADOS_URL` = адрес на Vercel.

**Как это работает на Vercel:**
- Постоянного AI-воркера нет: оценка нового лида выполняется сразу после запроса, который его создал.
- **Cron** из `vercel.json` раз в день в 05:00 UTC (8:00 МСК) собирает дайджест, готовит follow-up, досчитывает очередь
  и отправляет утреннюю сводку. На бесплатном тарифе cron можно не чаще раза в день; на Pro можно добавить
  `/api/cron/jobs` каждые 15 минут. Час сводки на Vercel задаётся расписанием в `vercel.json`, а не `DIGEST_HOUR`.
- Лимит работы функции — до 5 минут: генерация черновика (до минуты-двух) укладывается.
- Защита от подбора пароля на Vercel работает в пределах одного экземпляра функции — поэтому пароль должен быть длинным.

## 14. Переезд на VPS

1. На сервере: `cp .env.example .env`, заполни (как на Vercel + `POSTGRES_PASSWORD`, `TG_*`).
2. Перенеси базу:
   ```bash
   pg_dump "$DIRECT_URL_NEON" --no-owner --no-acl > leados.sql
   docker compose up -d db
   docker compose exec -T db psql -U leados leados < leados.sql
   ```
3. Запусти всё:
   ```bash
   docker compose up -d --build                        # приложение, миграции, AI-воркер
   docker compose --profile telegram up -d --build     # плюс Telegram-воркер
   ```
4. nginx/caddy рядом со StoreOS проксирует на `127.0.0.1:3100` с HTTPS. В nginx передавай реальный IP:
   `proxy_set_header X-Real-IP $remote_addr;` — на нём держится защита от подбора пароля.
5. Поменяй `APP_URL` на новый домен, переустанови закладки, в «Настройках» переподключи бота (или `TELEGRAM_CHAT_ID`).
6. В Vercel отключи проект (или удали cron), чтобы сводка не приходила дважды из двух мест.

На VPS AI-задачи выполняет сервис `ai-worker` (`AI_INLINE_JOBS=false` в compose), контейнер приложения проверяется
через `/api/health`. Бэкап: `docker compose exec db pg_dump -U leados leados > backup.sql`.

## 15. Переменные окружения

| Переменная | Где | Зачем |
|---|---|---|
| `DATABASE_URL` | везде | PostgreSQL (на Vercel — пулинговый адрес) |
| `DIRECT_URL` | сборка | прямой адрес базы для миграций, если `DATABASE_URL` через пулер |
| `BASIC_AUTH_USER`, `BASIC_AUTH_PASSWORD` | приложение | вход (в production обязательно, пароль от 12 символов) |
| `APP_URL` | приложение, воркер | публичный адрес: ссылки в уведомлениях, API, закладки |
| `API_TOKEN` | приложение, Telegram-воркер | доступ к `/api/*`, от 16 символов |
| `CRON_SECRET` | Vercel | доступ cron к `/api/cron/*`, от 16 символов |
| `ANTHROPIC_API_KEY`, `AI_MODEL` | приложение, AI-воркер | Claude API и модель (`claude-opus-5`) |
| `AI_AUTO_SCORE` | приложение | оценивать новые лиды автоматически (`true`) |
| `AI_INLINE_JOBS` | приложение | выполнять AI-задачи после запросов (по умолчанию: да на Vercel, нет на сервере) |
| `AI_WORKER_CONCURRENCY` | AI-воркер | задач одновременно (2) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | приложение, AI-воркер | уведомления; чат можно подключить в «Настройках» |
| `APP_TIMEZONE` | везде | часовой пояс дат, месяцев и сводки (`Europe/Moscow`) |
| `DIGEST_HOUR` | AI-воркер | час дайджеста и сводки на сервере (8) |
| `STALE_DAYS` | приложение, воркер | через сколько дней без движения лид зависший (5) |
| `DB_POOL_MAX` | приложение | подключений к базе на процесс (3 на Vercel, 10 на сервере) |
| `POSTGRES_PASSWORD` | Docker | пароль базы в compose |
| `TG_API_ID`, `TG_API_HASH`, `TG_SESSION`, `LEADOS_URL`, `LEADOS_API_TOKEN` | Telegram-воркер | раздел 4 |

## 17. Если что-то не работает

| Симптом | Что сделать |
|---|---|
| `pnpm` падает с `URL.canParse is not a function` | В терминале старый Node — `nvm use 24` |
| Закладка ничего не открывает | Разреши всплывающие окна для сайта |
| Окно закладки пишет «Страница не ответила» | Переустанови закладку — устарел адрес LeadOS |
| 2ГИС: «не нашёл данные карточки» | Обнови страницу карточки (F5) и нажми снова |
| «Слишком много неверных попыток входа» | Подожди 15 минут; проверь, не сохранён ли в браузере старый пароль |
| «AI не настроен» | Нет `ANTHROPIC_API_KEY` или сервер не перезапущен (на Vercel — Redeploy) |
| Новые лиды не оцениваются | Сервер: не запущен `pnpm worker:ai`. Vercel: смотри ошибки очереди на странице «AI» |
| Утренняя сводка не пришла | «Настройки»: бот и чат подключены? журнал отправок там же. Vercel: задан `CRON_SECRET`, выключена Deployment Protection |
| Telegram-воркер «молчит» | Процесс запущен? `LEADOS_URL`/`LEADOS_API_TOKEN` верные? На Vercel — Deployment Protection выключена |
| «Нет связи с базой данных» | Открой `/api/health` — он назовёт причину: `no_database_url`, `no_tables` (не прошли миграции), `bad_credentials`, `host_not_found`, `too_many_connections` |
| Сборка падает с `Can't resolve '@/generated/prisma/client'` | Prisma Client генерируется командой сборки; проверь, что Build Command не переопределён в панели |
| Выручка в аналитике меньше, чем на самом деле | Не отмечены оплаты — дашборд «Сделки без отмеченной оплаты» |
| После импорта старых сделок на дашборде много «Предложить доработки» | Так и задумано: прошлые клиенты — самый тёплый источник новых заказов. Отработанных отмечай галочкой в сделке |
| `prisma migrate dev` отказывается работать | Применяй миграции через `pnpm db:deploy` |
| После обновления страницы падают с `Unknown field` | Применили миграцию, а `pnpm dev` держит старый Prisma Client — перезапусти `pnpm dev` и воркер |
