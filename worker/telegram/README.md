# LeadOS · Telegram-воркер

Читает Telegram-каналы и супергруппы **от твоего личного аккаунта** (только те, где ты состоишь) и отправляет
новые посты в LeadOS. Фильтрация по ключевым словам, дедупликация и создание лидов происходят в LeadOS —
список каналов и слов меняется на странице `/telegram` без перезапуска воркера.

```
каждые POLL_INTERVAL секунд:
  GET  /api/telegram/channels          ← какие каналы читать (и пульс воркера)
  для каждого канала:
    Telethon: посты после lastMessageId (у нового канала — последние BACKFILL_LIMIT)
    POST /api/telegram/channels/:id/ingest   → LeadOS фильтрует, создаёт лиды, сдвигает lastMessageId
раз в DIALOGS_INTERVAL:
  POST /api/telegram/dialogs           ← каналы аккаунта для кнопки «Следить»
```

Воркер ничего не хранит локально: позиция чтения живёт в LeadOS, поэтому перезапуск или переезд ничего не теряет.
Повторная отправка той же пачки не создаёт дублей.

## Настройка и запуск

Пошагово — в [docs/INSTRUCTIONS.md § 4](../../docs/INSTRUCTIONS.md#4-telegram-каналы).

## Переменные

| Переменная | По умолчанию | |
|---|---|---|
| `TG_API_ID`, `TG_API_HASH` | — | из my.telegram.org |
| `TG_SESSION` | — | строка из `login.py` |
| `LEADOS_URL`, `LEADOS_API_TOKEN` | — | адрес LeadOS и его `API_TOKEN` |
| `POLL_INTERVAL` | 300 | секунд между циклами (минимум 60) |
| `BACKFILL_LIMIT` | 50 | сколько последних постов прочитать у только что добавленного канала; 0 — только новые |
| `MAX_POSTS_PER_CYCLE` | 1000 | сколько постов канала догонять за цикл после простоя |
| `DIALOGS_INTERVAL` | 1800 | как часто обновлять «Мои каналы» |

## Docker (VPS)

Сервис `telegram` в корневом `docker-compose.yml` включается профилем `telegram` — см. [docs/INSTRUCTIONS.md § 8](../../docs/INSTRUCTIONS.md#8-деплой-на-vps).

## Тесты

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Без Telegram: фейковый клиент отдаёт настоящие типы Telethon. Интеграционный тест против запущенного LeadOS
включается переменными `LEADOS_URL`, `LEADOS_API_TOKEN` и `LEADOS_IT_CHANNEL_ID` (id заранее созданной записи
канала `leados_it_channel`).

## Ограничения и безопасность

- Чтение идёт обычными запросами истории с паузой между циклами — как если бы ты сам пролистывал каналы.
  Если Telegram просит подождать (FloodWait), воркер ждёт указанное время.
- Воркер **только читает**: не пишет сообщений, не вступает в каналы, не трогает контакты.
- Обычные (не супер-) группы не поддерживаются — у их сообщений нет ссылок.
